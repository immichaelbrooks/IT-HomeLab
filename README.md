## Home Lab Projects

### 01 — Raspberry Pi DNS Filtering & Automated Recovery

**Technologies:** Linux, Raspberry Pi OS, AdGuard Home, Bash, systemd, UFW, DNS, SSH

Configured a Raspberry Pi Zero as a network-wide DNS filtering server using AdGuard Home.

After experiencing occasional DNS interruptions, I developed a Bash health-check script and configured systemd automation to monitor DNS availability and attempt automatic recovery.

**Skills demonstrated:**
- Linux system administration and troubleshooting
- DNS configuration and network services
- Bash scripting and automation
- Firewall configuration and access control
- Service monitoring and reliability
